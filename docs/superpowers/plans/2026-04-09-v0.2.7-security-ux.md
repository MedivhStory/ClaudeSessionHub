## Task 1: Keychain 迁移

**核心决策：迁移路径**

```
启动时:
  1. 尝试从 Keychain 读 API key
  2. 如果 Keychain 无 key，检查 settings.json 里的 plaintext key
  3. 如果 settings.json 有 key → 迁移到 Keychain → 从 settings.json 删除 key
  4. 后续所有 key 读写走 Keychain
```

**实现：**

**抽象层设计（测试隔离）：**

定义 `SecretStore` protocol，两个实现：
```swift
protocol SecretStore: Sendable {
    func save(key: String, value: String) throws
    func load(key: String) -> String?
    func delete(key: String)
}

struct KeychainSecretStore: SecretStore { ... }  // 真实 Keychain，生产用
final class InMemorySecretStore: SecretStore { ... }  // 内存，测试用
```

- 生产环境：`KeychainSecretStore(service: "com.claudehub.llm")`
- 测试 / UI test mode：`InMemorySecretStore()`
- SettingsStore init 接受 `secretStore: SecretStore` 参数，默认 Keychain

**新建 `Sources/.../Services/SecretStore.swift`：**
- `SecretStore` protocol
- `KeychainSecretStore`：Security framework（SecItemAdd/CopyMatching/Update/Delete）
- `InMemorySecretStore`：Dict-based，测试专用

**修改 `LLMConfig`：**
- `apiKey` 从 Codable **encode** 中排除（encode 时跳过）
- `init(from decoder:)` 中 apiKey 仍然尝试 decode（兼容旧 JSON），默认空

**修改 `SettingsStore`：**
- 新增 `private let secretStore: SecretStore` 属性
- init 接受 `secretStore` 参数（默认 `KeychainSecretStore()`）

- `load()` 迁移路径（**关键**）：
  ```
  1. 读 settings.json 得到 raw [String: Any]
  2. 从 raw["llmConfig"] dict 中直接提取 legacy apiKey（不靠 JSONDecoder）
  3. 用 JSONDecoder decode LLMConfig 其余字段
  4. 尝试从 secretStore 加载 apiKey
  5. 如果 secretStore 无 key 但 raw JSON 有 legacy key：
     → 写入 secretStore
     → 从 raw dict 删掉 apiKey
     → 重新 save() 去掉 plaintext
  6. 把最终 apiKey 赋给 llmConfig
  ```

- `setLLMConfig()`: apiKey 写 secretStore，其他字段写 JSON
- `save()`: llmConfig encode 不含 apiKey

**ClaudeSessionHubApp.swift：**
- UI test mode：传 `InMemorySecretStore()` 给 SettingsStore

**测试：**
- `testInMemorySecretStoreSaveAndLoad`
- `testMigrationFromPlaintext` — 手写含 apiKey 的旧 JSON → load 后 key 在 secretStore，JSON 里 key 被清除
- `testKeychainDeleteOnEmptyKey`
- `testNoMigrationWhenSecretStoreAlreadyHasKey`

## Task 5: `relativeTime` 去重

SessionTileView 和 LLMPanelView 都定义了相同的 `relativeTime(_:)` 函数。

提取到公共位置：

```swift
// Sources/.../Views/Common/DateFormatting.swift
extension Date {
    var relativeFormatted: String {
        let formatter = RelativeDateTimeFormatter()
        formatter.unitsStyle = .abbreviated
        return formatter.localizedString(for: self, relativeTo: Date())
    }
}
```

两个 view 改为 `session.lastActiveAt.relativeFormatted`。

**Files:**
- Create: `Sources/.../Views/Common/DateFormatting.swift`
- Modify: `Sources/.../Views/Sessions/SessionTileView.swift`
- Modify: `Sources/.../Views/Sessions/LLMPanelView.swift`
