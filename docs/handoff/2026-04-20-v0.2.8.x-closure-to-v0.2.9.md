## Notable decisions and outcomes

### #5 — UUID fallback title (partially addressed)

English verb pattern expanded from 16 to 60+ imperatives in v0.2.8.3. Improves title extraction for sdk-cli sessions starting with "Generate", "Verify", "Analyze", etc.

**Known limitation**: The 10+50 entry window in `extractSignals` / `extractTitle` still exists. Sessions where the first meaningful user text is buried past entry index 10 (due to `queue-operation`, `attachment`, or meta noise) may still fall through to UUID prefix. The AI enhance path (`extractEnhanceInputs`) already does a full scan and doesn't have this limitation.

A deeper fix would require expanding the head window or switching `extractSignals` to a full-scan path. This is a performance/correctness trade-off deferred for later re-evaluation.

### #6 — "Keychain scoping" (misdiagnosis, closed)

Original report: "Release build from DerivedData can't read DashScope key, dev build can."

Root cause: The `isConfigured` check returned false on app startup because `ensureApiKeyLoaded()` was lazy — deferred until AI features were triggered. The API key existed in `FileSecretStore` but wasn't loaded into `llmConfig` yet.

Resolution: `SettingsStore.init()` now calls `ensureApiKeyLoaded()` eagerly (commit `1500f1c`, v0.2.8.2). `FileSecretStore` uses pure filesystem I/O with no Keychain interaction or code-signing dependency. The "Keychain scoping" framing was a misdiagnosis.

### #11 — `--ui-test-mode` stacked sessions (intentional, closed)

`FixtureProvider` returns 4 deterministic sessions. The app's detail pane is a `SessionListView` with vertically scrolling expandable tiles — all 4 appear so XCUITests can locate them by accessibility identifiers. This is the intended test-harness design.

### v0.2.8.1 release anomaly

v0.2.8.1 was auto-generated as a draft release by `release.yml` but was never manually published. It remained in draft state until 2026-04-20 when it was published with a supersede note pointing to v0.2.8.3. The .dmg and .zip assets are valid but users should use the latest release.
